# 微信小程序开发版

原生 WXML / WXSS / JavaScript，不是 web-view 套壳。当前包含：首页六场景、点按场景菜单、动态报备表单、照片上传、本人事项进度、学生/教师注册登录、管理员登录。地图点位编辑、宿舍管理与数据驾驶舱仍在网页工作台，尚未迁入原生端。

## 导入

在微信开发者工具选择「导入项目」，项目目录选当前 miniprogram 文件夹（不是 Django 根目录）。使用自己的小程序 AppID；project.config.json 中 touristappid 仅用于界面体验，不是可正式发布的 AppID。

工具使用自身内置运行环境，不需要 npm 安装。编译入口 pages/home/index。

## 接口配置

服务器地址位于 utils/api.js 的 BASE_URL。正式联调需在小程序账号后台配置 HTTPS request 与 uploadFile 合法域名： https://campus-mosquito-demo.onrender.com 。当前托管域名能否通过微信的配置校验需由账号后台确认；不能配置时需换成符合微信要求的自有服务器域名。

未连接时首页只展示明确标注的本地预览场景，不伪造保存成功或处理记录。提交、查询、登录必须连接后端。账号接口 /api/mini/ 使用 Django 会话及 CSRF 校验，照片接口仍受后台权限保护。

AppID 可替换为自己的值；不要把 AppSecret 写入代码或公开仓库。不包含 wx.login / 微信身份绑定、订阅消息、正式发布配置。下载源码不等于审核上线。

现有 Render 免费服务器会休眠，首次请求可能较慢，照片也可能丢失。只用于参赛演示，不提交真实患者信息。此版本尚待微信开发者工具实际编译与真机联调验收。
