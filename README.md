# 校园灭蚊排查系统网页版

这是由原 C 语言控制台程序升级而来的单页网页应用，面向广东医科大学东莞校区后勤排查场景。

## 已实现功能

- 七大片区初始化与风险统计
- 点位新增、编辑、删除、搜索和排序
- 高危未消杀优先的排查任务队列
- 排查日志新增、筛选和时间线展示
- 日志完成整改时自动同步点位消杀状态
- 浏览器本机持久保存，无需额外安装数据库
- 桌面与手机自适应界面
- WebMCP 工具：查询点位、新增点位、记录排查

## 本地运行

进入 `dist` 目录并启动任意静态文件服务器，然后在浏览器访问对应地址即可。直接部署时，站点入口为 `dist/index.html`。

## 文件结构

- `dist/index.html`：页面结构与表单
- `dist/styles.css`：视觉样式与响应式布局
- `dist/app.js`：业务逻辑、数据持久化、任务调度与 WebMCP 工具
- `source/`：用户提供的原始 C 程序和需求文档副本
